# 15 — Nonverbal Communication | Learning Lab

A responsive, standalone educational web application in the Central Hub learning repository series.

## Modules

- **Explore** — overview, nine domain cards, and learning progress.
- **Theory Library** — 32 frameworks with searchable claims, observation methods, examples, interpretive cautions and foundational reading leads.
- **Concept Map** — keyboard-accessible interactive SVG framework explorer, with domain filtering.
- **Social Interaction Lab (V3)** — four fictional multi-character social scenarios with decision points, alternative responses, contextual feedback, local learning records and reflection export.
- **Communication Simulator (V2)** — six adjustable nonverbal and contextual dimensions, live stylized interaction diagram, multiple plausible interpretations, reflection saving and handoff to the Cue Analysis Lab.
- **Cue Analysis Lab** — eight-step uncertainty-aware worksheet that separates observation from inference and prompts alternative hypotheses.
- **Observation Lab** — structured observational coding log with ten channels and JSON export.
- **Compare** — side-by-side framework comparison.
- **Case Studies** — six contextual scenarios with revealable explanations.
- **Recall Lab** — 16 prompts, self-rated review intervals and JSON export.
- **Study Path** — five sequenced phases with local progress tracking.
- **Journal** — six reflection prompts with local saving and JSON export.

## GitHub Pages

Open **Settings → Pages** and configure **Deploy from a branch → main → /(root)**.

Expected site: https://obiwandac0-d.github.io/15-Non-Verbal-Communication-/

All code is in `index.html`. No dependencies, external APIs, account, camera or microphone are required. Progress and notes use browser localStorage and do not sync between devices. Export JSON to back up data.

## Research and ethics

Nonverbal behavior is context-dependent. A gesture, facial expression, eye-contact pattern or vocal feature does not independently establish deception, diagnosis, attraction, consent or intent. The often-repeated '93% of communication is nonverbal' generalization misuses narrow experimental results. Consider culture, disability, neurodiversity, power, setting and competing explanations.

Bibliographic entries are introductory reference leads rather than independently verified systematic evidence reviews. This app is not a diagnostic or lie-detection tool. Do not record identifiable third-party information without permission.
